Commands:-


- sudo apt update               - it updates the entire system
- sudo apt upgrade -y           - it upgrade the system file and configurations
- sudo apt install nginx -y     - it install the nginx application on linux os
- sudo apt install curl -y      - it install the curl application on linux os
- dpkg -l                       - it displays a list of all packages konwn to dpkg  
- apt list --installed          - it shows all installed applications list on linux os
