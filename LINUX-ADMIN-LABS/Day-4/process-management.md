commands:-                              Description

- ps aux -                       It shows active process list
- top    -                       It shows all process by linux including users,root,etc,
- htop   -                       Better version of top it includes ram and memeory usage and cpu usage
- kill pid -                     To kill a process by pid   
- kill -9 PID -                  To forcefully kill a process by pid
- systemctl status ssh -         It shows the service status
- systemctl start ssh  -         It start the service
- systemctl enable ssh -         It enable/on the service it temporerly stop
